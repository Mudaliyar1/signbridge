K-Nearest Neighbors (KNN)
Instance-Based

Classifies gestures by measuring Euclidean or Manhattan distance against normalized training landmark vectors. Hand posture is assigned based on majority vote of the K closest neighbors.

Input Vector: 63-D Normalized Hand Landmarks ($21 \times 3$)
Distance Metrics: Euclidean ($L_2$), Manhattan ($L_1$)
Hyperparameters: $n\_neighbors \in \{1, 3, 5, 7\}$, $weights \in \{\text{uniform, distance}\}$
Presence Gating: Strict NO_HAND rejection if landmarks absent
Support Vector Machine (SVM)
Max-Margin

Learns optimal separating hyperplanes between distinct ISL gesture classes in high-dimensional landmark space. Features are scaled using StandardScaler fitted strictly on the training partition.

Input Vector: 63-D Normalized Hand Landmarks ($21 \times 3$)
Feature Scaling: StandardScaler (Strict Train Fit, Zero Test Leakage)
Kernels: Radial Basis Function (RBF), Linear
Hyperparameters: $C \in \{0.1, 1.0, 10.0\}$, $\gamma \in \{\text{scale, auto}\}$
Decision Tree
Rule-Based

Recursively partitions normalized landmark coordinate space using axis-aligned orthogonal decision rules based on information gain (Entropy) or Gini impurity.

Input Vector: 63-D Normalized Hand Landmarks ($21 \times 3$)
Splitting Criteria: Gini Impurity, Shannon Entropy
Hyperparameters: $max\_depth \in \{5, 10, \text{None}\}$, $min\_samples\_split$
Explainability: Full white-box hierarchical decision trace
CustomSignCNN (Deep Learning)
Neural Network

Our scratch-built 4-block Convolutional Neural Network trained on raw $224 \times 224$ hand-cropped images. Zero pretrained weights. Evaluated on the identical held-out test partition.

Input Tensor: RGB Image ($3 \times 224 \times 224$)
Architecture: 4 Conv Blocks (32, 64, 128, 256), BatchNorm, MaxPool, FC(512)
Presence Gate: Classical & MediaPipe hand presence gating
Pretrained Weights: None (Strict scratch training policy)
